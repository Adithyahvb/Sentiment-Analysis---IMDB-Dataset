Sentiment Analysis using custom LSTM, Pretrained AWD-LSTM(ULMFiT) and BERT based transformer model. 

Sentiment Analysis is a Natural Language Processing (NLP) technique used to determine the emotional tone or opinion expressed in a piece of text.

In simple terms, it answers the question:

"Is the text expressing a positive, negative, or neutral opinion?"

Organizations use sentiment analysis to understand customer opinions from:

Product reviews

Social media posts

Customer feedback

Survey responses

Support tickets

News articles

Types of Sentiment Analysis:

1. Binary Sentiment Analysis

2. Multi-class Sentiment Analysis

3. Fine-Grained Sentiment Analysis
